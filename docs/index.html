UISP Extension

Login sem senha em equipamentos cadastrados no UISP, pelo navegador ou pedindo a um assistente de IA.

1. Instale e configure a extensão

  1. Instale pela Chrome Web Store ou pelo Firefox Add-ons.
  2. Sem as lojas: baixe o pacote da última release (Chrome ou Firefox). No Chrome, descompacte e use chrome://extensions › Modo do desenvolvedor › Carregar sem compactação. No Firefox o pacote não é assinado e só carrega temporariamente em about:debugging.
  3. Abra o popup da extensão, informe a URL do UISP terminando em /nms/api/v2.1 e um token de API.
  4. Clique em Save e depois em Habilitar uso por assistente de IA, permitindo o acesso ao endereço do UISP. Uma aba desta página abre para salvar uma cópia local, que funciona mesmo com o GitHub fora.

O token fica guardado só dentro da extensão. Nem esta página nem o assistente de IA têm acesso a ele.

2. Instale a skill no seu assistente de IA

O assistente precisa ter acesso ao navegador. Cole nele:

Instale a skill UISP Login de https://intera-net-br.github.io/uisp-extension/

Ou instale manualmente:

  • Baixe o uisp-login-skill.zip (ou o SKILL.md) e envie na área de skills do seu assistente.
  • Em ferramentas com marketplace de plugins: 
    /plugin marketplace add intera-net-br/uisp-extension
/plugin install uisp-login@uisp-extension

Depois é só pedir, por exemplo: "entra no rádio 10.0.0.5". O assistente abre a página do equipamento e, a partir dela, vai para login.html#10.0.0.5; a extensão reconhece que o pedido partiu do próprio equipamento e entra sozinha.
